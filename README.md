# STANBEYOND-Labs-StudyForge
a 100% local single-file study app: notes → auto-generated flashcards (deterministic, no AI) → quizzes → SM-2 spaced repetition. No account, no cloud, works offline.

**Turn your notes into flashcards and quizzes — with zero AI, zero cloud, and zero accounts.** STANBEYOND StudyForge is a single self-contained HTML file: take notes, auto-generate flashcards with a deterministic pattern-matching engine, build quizzes, and review with real SM-2 spaced repetition. Your data never leaves your browser.

## Why StudyForge?

- **No AI inside.** Flashcards are generated by an inspectable, deterministic script — six pattern rules, every candidate showing its rule and confidence. Same notes → same cards, every time.
- **Truly offline.** One HTML file. No server, no signup, no telemetry, no subscription. Open it from a USB stick if you want.
- **A complete study loop.** Notes → flashcards → quizzes → spaced-repetition review → stats. Not a demo, a daily driver.
- **Tested like it matters.** 20,955 assertions across six suites, zero failures — including hostile fuzz input, 48 realistic human-written notes, and full UI walkthroughs in a real browser.

## Features

**📝 Notes** — notebooks, tags, full-text search, pinning, sorting, markdown-lite toolbar with live preview, templates (Blank / Cornell / Vocabulary / Q&A), autosave with save indicator, word count + reading-time estimate, Ctrl+S.

**⚡ Flashcard generation** — six deterministic rules scan your note; you tick the candidates you want. Cards are fully editable afterwards.

| Rule | Pattern | Confidence |
|---|---|---|
| Definition line | `Term: definition` / `Term = …` / `Term - …` (bullets OK) | 95% |
| Bold term | `**Term** is/are/means …` | 90% |
| Q & A | `Q:` / `A:` (or `Question:` / `Answer:`) pairs | 95% |
| Heading | `## Heading` + paragraph | 80% |
| Fill in the blank | key term blanked from its sentence | 70% |
| Key term | frequent/capitalized term → its best sentence | 50% |

**🗂 Decks** — flip-through, manual add/edit/delete, **bulk import from text** (`front | back`, `front: back`, `Q:`/`A:` pairs), **CSV export** (Anki-friendly), multi-select delete/move, sorting (newest / A–Z / due first), card search, duplicate, print stylesheet, **leech detection** (🪲 badge on cards failed 4+ times), per-deck mastery %.

**🎯 Quizzes** — multiple choice (deck-sourced distractors), true/false, fill-in-the-blank, matching. Seeded shuffles (same seed + deck = same quiz), optional timer with auto-submit, per-question feedback, answer review, and per-run history with question-by-question breakdowns.

**🔁 Review** — SM-2 spaced repetition across all decks (Again/Hard/Good/Easy), keyboard shortcuts (`Space`, `1`–`4`), due badge, streaks, configurable daily goal with progress bar.

**📊 Stats** — cards/decks/notes, due-now, reviews today/total, quiz averages, per-deck mastery and ease, 7-day activity chart, leech count.

**⚙️ Data** — everything in `localStorage`; JSON export/import (merge-safe), storage meter, full wipe, light/dark theme.

## Honest limitations

- Generation is heuristic: messy, unstructured notes yield fewer/weaker candidates. Formatting tips are built into the app.
- `localStorage` is per-browser (~5MB); the Data tab shows usage and JSON export covers backup/migration.
- Quiz distractors come from the same deck, so tiny decks (<4 cards) fall back to true/false + fill-in-the-blank.
